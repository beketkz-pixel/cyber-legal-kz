# cyber-legal-kz — юрист по кибербезопасности и персональным данным Казахстана

Плагин для Claude: отвечает на вопросы по праву Республики Казахстан в сфере кибербезопасности, цифровизации и персональных
данных **по официальным текстам актов**, со ссылкой на статью, пункт и подпункт и с дословной цитатой нормы.

Версия плагина: 0.6.2. Тестовая версия: ответы — консультация по текстам актов, **не официальное юридическое заключение**.

## Что умеет

- Уведомления об инцидентах и утечках: кого, в какой срок, по какой норме.
- Проверки, предписания, штрафы (КоАП), обжалование (АППК), уголовная ответственность (УК).
- Критически важные цифровые объекты (КВЦО), испытания, ЦОД, резервная платформа, журналирование.
- Персональные и медицинские данные: согласие, сбор и обработка, меры защиты, трансграничная передача.
- Единые требования № 832, приказы и постановления по кибербезопасности.
- Банки, платёжные и финансовые организации: требования к ИБ, банковская тайна, антифрод; стандарт PCI DSS.
- Заключения, ответы регулятору, проверка договора с подрядчиком; вопросы и ответы на казахском языке.

Как устроено: в плагине — короткий навык (порядок работы и правила ответа) и подключение к серверу норм
`https://kb.nakasse.kz`. Тексты 38 актов, подбор норм под вопрос, справочники и сверка цитат живут на сервере; модель
открывает только нужные статьи и пункты.

## Установка

### Claude в браузере и приложение Claude (claude.ai)

1. Скачайте архив `cyber-legal-kz-plugin.zip` со страницы [Releases](../../releases/latest).
2. В Claude откройте **Персонализация → Плагины → Загрузить плагин** и выберите архив. Распаковывать его не нужно.
3. Откройте страницу плагина и убедитесь, что он включён, а на вкладке «Коннекторы» подключён сервер `cyber-legal-kz`.
4. Начните новый чат и задайте вопрос — например: «Утекла база клиентов интернет-магазина. Кого и в какой срок уведомлять?»

Загрузка плагинов доступна не на всех тарифах; если пункта «Плагины» нет — подключите только сервер (ниже).

### Claude Code

```bash
claude plugin marketplace add beketkz-pixel/cyber-legal-kz
```

```bash
claude plugin install cyber-legal-kz@cyber-legal-kz-marketplace
```

### Только сервер норм (любой клиент с поддержкой MCP)

Адрес сервера записан в файле [`cyber-legal-kz/.mcp.json`](cyber-legal-kz/.mcp.json) (тип подключения — HTTP, без входа: ключ
стоит в самом адресе). В claude.ai: **Персонализация → Коннекторы → Добавить пользовательский коннектор**, вставьте адрес.
Без навыка сервер тоже работает, но порядок работы и правила ответа модель не получит.

## Как проверить, что работает

В ответе должны быть ссылки вида «ст. 25 п. 2 пп. 8) Закона № 94-V» и цитаты в кавычках, а в ходе ответа — вызовы
инструментов `pick_norms` и `get_norm`. Если модель отвечает «сервер не подключён» — проверьте шаг 3.

## Ограничения

- Корпус — 38 актов в редакциях на ноябрь 2026 года; вышла ли более новая редакция, плагин не проверяет.
- Нет текстов УПК, ГПК, Закона о государственных секретах и ряда правил Национального Банка — плагин говорит об этом прямо.
- Справочники и подбор норм составлены с помощью модели и сверены скриптами с текстами актов, юрист их не вычитывал.
- Доступ — по общему ключу в адресе сервера. Ключ может быть сменён: если плагин перестал подключаться, скачайте свежий
  архив из Releases.
- Сервер не хранит тексты вопросов и ответов; в журнале — только время, адрес и название вызванного инструмента.

## Источники

Тексты актов Республики Казахстан — информационно-правовая система «Әділет» (adilet.zan.kz). PCI DSS — стандарт
PCI Security Standards Council; цитируется по английскому тексту.
