# Плагин `cyber-legal-kz`

Юрист по кибербезопасности, цифровизации и персональным данным Казахстана. В плагине две части:

- навык `cyber-legal-mcp` — порядок работы и правила ответа (текстов актов в нём нет);
- подключение к серверу норм `cyber-legal-kz` (`.mcp.json`) — он отдаёт тексты актов, подбор норм, справочники и сверку цитат.

Без сервера навык ничего не знает: он скажет, что сервер не подключён. Как установить — в `README.md` в корне репозитория.
